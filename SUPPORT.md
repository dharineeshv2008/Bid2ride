# Getting Support for Bid2Ride

Welcome to the Bid2Ride community! If you need help using, building, or contributing to Bid2Ride, here are the official channels available.

---

## 🔍 Frequently Asked Questions (FAQ)
Before asking a question, please check our [README FAQ](README.md#frequently-asked-questions) and [Installation Guide](docs/INSTALLATION.md). Many common environment setup and build questions are addressed there.

---

## 💬 Community Discussions
For general questions, architecture discussions, or setup guidance, please use **[GitHub Discussions](https://github.com/john2010may/bid2ride/discussions)**:

- **Q&A**: Ask technical or environment setup questions.
- **Ideas & RFCs**: Suggest high-level architecture ideas or feedback.
- **Showcase**: Share your deployments or custom integrations.

---

## 🐛 Bug Reports & Feature Requests
If you have identified a bug or have a concrete feature request:
- Search existing [GitHub Issues](https://github.com/john2010may/bid2ride/issues) to verify it hasn't already been reported.
- If it's a new issue, submit a report using the [Bug Template](.github/ISSUE_TEMPLATE/bug_report.md) or [Feature Template](.github/ISSUE_TEMPLATE/feature_request.md).

---

## 🔐 Security Issues
For security vulnerabilities, please refer to our [Security Policy](SECURITY.md) and report privately instead of using public issues.
